# WMS Nexus - Уроки та Помилки (Lessons & Mistakes)

Цей файл створено для фіксації помилок, допущених під час розробки, та висновків, щоб уникати їх у майбутньому.

## 2026-08-06
1. **CSS-in-JS Синтаксис у React (inline styles):**
   - **Помилка:** Використання kebab-case (наприклад, `justify-content: 'space-between'`) замість camelCase у властивості `style`. Це призвело до помилки збірки Vite (`Expected "}" but found "-"`).
   - **Висновок:** Завжди перевіряти, що inline styles у React (JSX/TSX) написані у camelCase (наприклад, `justifyContent`).
2. **Перезапис файлів між субагентами:**
   - **Помилка:** Коли багато субагентів працюють одночасно, вони можуть конфліктувати при записі в один файл (наприклад, `index.css`).
   - **Висновок:** Завжди доручати створення глобальних файлів (як `index.css` або `types.ts`) одному специфічному субагенту *до* того, як інші почнуть будувати UI-компоненти, або чітко розмежовувати їх зони відповідальності.
